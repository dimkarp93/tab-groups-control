## Summary (лимит 250 символов)

```
Управление нативными группами вкладок Firefox с клавиатуры: сворачивание и разворачивание, переход к группе, сохранение и восстановление состояния окна, создание и пересортировка групп. Данные не покидают браузер.
```

## Description

```
Tab Groups Control управляет нативными группами вкладок Firefox (API tabGroups) полностью с клавиатуры — без боковой панели, без отдельного менеджера вкладок и без аккаунта.

ЧТО УМЕЕТ

• Сворачивать и разворачивать группу по номеру или все группы разом
• Переходить к первой вкладке нужной группы
• Создавать группу для текущей вкладки — с именем и цветом, ещё не занятым в этом окне
• Добавлять текущую вкладку в существующую группу
• Менять порядок групп перетаскиванием строк в диалоге
• Сохранять состояние окна и восстанавливать его позже — с именами и цветами групп, свёрнутостью и порядком вкладок
• Держать несколько именованных профилей снимков (default, work, reading, …), переключаться между ними, очищать и удалять
• Экспортировать профиль в JSON-файл и импортировать на другой машине

ГОРЯЧИЕ КЛАВИШИ

Ctrl+Alt+T — открыть список групп, затем цифра
Ctrl+Alt+0 — свернуть или развернуть все группы
Ctrl+Alt+1 … Ctrl+Alt+9 — свернуть или развернуть N-ю группу
Alt+Shift+1 … Alt+Shift+9 — перейти к первой вкладке N-й группы
Ctrl+Alt+N — новая группа для текущей вкладки
Ctrl+Alt+A — добавить текущую вкладку в группу
Ctrl+Alt+O — изменить порядок групп
Ctrl+Alt+S / Ctrl+Alt+R — сохранить / восстановить состояние окна
Ctrl+Alt+W — закрыть все вкладки вне групп
Ctrl+Alt+C / Ctrl+Alt+D — очистить активный профиль / удалить профиль

Любое сочетание переназначается в about:addons → шестерёнка → Управление сочетаниями клавиш. В Linux часть сочетаний по умолчанию занята системой (Ctrl+Alt+T обычно открывает терминал, Alt+Shift переключает раскладку) — переназначение решает вопрос.

ПРИВАТНОСТЬ

Данные не покидают браузер. Снимки лежат в локальном хранилище расширения; экспорт происходит только по нажатию кнопки и с вашим выбором файла. Никаких сетевых запросов, аналитики и аккаунтов.

ТРЕБОВАНИЯ

Firefox 140 или новее, десктоп. Группы обрабатываются в текущем окне.

Интерфейс по умолчанию английский, переключается на русский, когда язык интерфейса Firefox — русский.

Исходный код: https://github.com/dimkarp93/tab-groups-control
```
